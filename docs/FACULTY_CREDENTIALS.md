# Institutional Faculty Credentials & Running Model Directory

This directory lists all **60 faculty members** across all 5 engineering departments. Every faculty member has an active MySQL account, an assigned weekly teaching schedule, student class rosters, saved attendance session logs, and examination grading sheets.

### How to Log In as Any Faculty:
1. Navigate to **http://localhost:3000** (or your local frontend URL).
2. Select the **Faculty** role tab.
3. Enter either the **Faculty Code** (`FAC-001` to `FAC-060`) or **Faculty Email** as the login identifier.
4. Enter the faculty's **Primary Password** (`<FirstName>@<FacultyCode>`, e.g. `Ashwini@FAC001`, `Varun@FAC002`) or the universal fallback (`Faculty@2026`).
5. Click **Sign In to Faculty Portal**.

> [!NOTE]
> The full spreadsheet is available as **`docs/FACULTY_CREDENTIALS.csv`** for opening in Microsoft Excel or Google Sheets.
