# Institutional Student Credentials & Running Model Directory

This directory lists all **1,000 active students** enrolled in the University ERP system across all 5 departments and 20 sections. Every student is linked to a live MySQL account and a fully functioning running model (academics, weekly timetable, attendance records, semester marks, fee dues, library issues, and placement drives).

### How to Log In as Any Student:
1. Navigate to **http://localhost:3000** (or your local frontend URL).
2. Select the **Student** role tab.
3. Enter either the **Roll Number** or **Student Email** as the login identifier.
4. Enter the student's **Primary Password** (`<FirstName>@<RollNo>`, e.g. `Kavya@31001`) or the universal fallback (`Student@2026`).
5. Click **Sign In to Student Dashboard**.

> [!NOTE]
> The full spreadsheet is available as **`docs/STUDENT_CREDENTIALS.csv`** for opening in Microsoft Excel or Google Sheets.
